# Original project artwork

Created locally on 23 November 2026 for Brand Guidelines to Slides. No existing project logo was recovered; the BG monogram derives from the first two words of the project title. It is a project identifier, not a vendor logo or an official corporate-brand asset.

Palette: charcoal `#111827` and off-white `#F9FAFB`, selected as a neutral high-contrast pair. Typography is rendered through locally available system fonts; no font files are bundled.

The canonical editable mark is `mark.svg`. PNG variants are 16, 32, 48, 180 and 512 pixels square. The Academy image is `thumbnail.png`, 1024 × 1024 pixels, with the exact uppercase title and one BG mark. The thumbnail and 16/32 px variants were visually inspected. Local Chromium rendered the images; no paid image generation API or stock asset was used.

These original project assets are included in the proposed MIT release. This does not license any unrelated brand assets used in future tasks.
