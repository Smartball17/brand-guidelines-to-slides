# Brand Guidelines to Slides

A reusable Manus Skill that turns evidence from an existing brand into practical presentation guidelines and a compact style brief. When requested, it supplies brand rules to the official Manus Slides workflow for a template or content deck. It is not a naming, logo-design or rebranding tool.

## Install and use

Download [the v1.0.0 `.skill` package](dist/brand-guidelines-to-slides-v1.0.0.skill). Import it into **My Skills** if your interface offers that action, or attach it to a Manus task and use the native Skill card when offered. Account installation and interface-specific import have not been verified for this release.

The runtime [SKILL.md](skills/brand-guidelines-to-slides/SKILL.md) and its four references are in Spanish. This English documentation stays outside the runtime package. The native archive was built with the official Skill packager; do not rename a Markdown guide as a PPTX or assume it is a Slides import format.

Attach authorized brand materials, then ask for guidelines or a template. See [two example prompts and an out-of-scope request](examples/usage.md).

## Inputs, outputs and requirements

Use an existing brand manual, approved presentation samples, authorized assets or accessible official sources. Default outputs are `brand-presentation-guidelines.md` and `slides-style-brief.md`. Rules are classified as official, observed, proposed or unknown, with source locations. Color roles, typography, logos, layouts, charts and tables are covered.

Guidelines-only work needs file reading and writing. Creating or editing a deck requires the official `slides` Skill and its available tools. Research and document-format tools are conditional dependencies. No paid API or credential is required by this method; Manus usage and optional paid services may still incur costs. Obtain separate approval before paid services or public sharing.

## Validation and limits

The official structural validator and native packager passed on 23 November 2026. The preserved October test record reports one synthetic documentary execution and three simulated responses with explicit Skill loading. Original behavioral outputs were lost in a sandbox reset and are unavailable. See [validation evidence and boundaries](VALIDATION.md).

Automatic activation, account installation, brand import, actual Slides/PPTX creation, export, object editability, opening in PowerPoint and real-brand fidelity have **not** been verified with this Skill. Font availability and current Slides capabilities need checking for each request. Markdown guidelines are not a promised native brand-import format. No production-readiness, universal-compatibility or savings claim is made.

## Privacy and rights

This neutral package contains no real brand manual, client asset, embedded credential or third-party logo identified in the reviewed text. This is a limited static review, not a security audit. Publicly downloadable brand assets are not automatically licensed for reuse. Keep confidential inputs outside a public release and verify font, image, logo and template rights for the intended destination.
