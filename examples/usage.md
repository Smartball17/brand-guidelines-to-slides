# Usage examples

These suggested prompts are not executed tests or available outputs. Attach your own authorized inputs; no brand manual, asset, template or `.skill` package is included here.

## 1. Guidelines only

> Use Brand Guidelines to Slides with the attached authorized brand manual and approved presentation sample. Create practical presentation guidelines and a reusable Slides style brief. Separate official rules, observed patterns, proposed adaptations and unknowns, with source locations. Work only from these files; do not create a deck, publish, upload or use paid services. Identify missing evidence and rights checks, and leave brand import unverified.

Slides is not required for this documentary request.

## 2. Requested presentation template

> Use Brand Guidelines to Slides with the attached authorized manual and assets. Prepare guidelines and a compact style brief, then use the current official Manus Slides workflow to create a template and export a PPTX if supported. Include a dense-content layout and a table using clearly synthetic data. Keep text and tables editable where supported; document font substitutions and separate verified checks from pending ones. Do not assume direct brand-guidelines import or invent a template ID. Do not publish or use paid services without separate approval.

This request requires the official `slides` Skill and available tools. Export, editability, opening in PowerPoint and fidelity must each be checked; this prompt does not establish that they work.

## Negative: new identity

> Invent a new startup name and logo, then write its brand guidelines.

This is outside the Skill's scope: it adapts an existing identity. Route the request to a naming/brand-identity method instead of fabricating an existing brand or claiming this Skill covers that work.

## Input caution

Use only materials authorized for the intended destination. Remove unnecessary secrets and private business data before sharing. A license proposal for the neutral method does not grant rights to fonts, logos, photographs or templates supplied by others.
